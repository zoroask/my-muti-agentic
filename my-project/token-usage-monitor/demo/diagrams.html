Token Usage Monitor - Diagrams

History view, not real-time. Data updates only when you click Refresh.

1. Working flow

Transcripts are read-only. Counts go to SQLite. The browser reads SQLite through FastAPI.

2. Refresh logic

Unchanged files are skipped. Bad lines are logged and skipped.

3. Data model

Two tables. No prompt or response text is stored.

4. Deployment

Everything runs on your Windows PC. Nothing is public.
