# Effects, timing and resolution order
as_of: 2026-10-16
source: Comprehensive Rules Ver. 1.10.0 (2026-10-16) section 10

## Effect types (10-1)
- Constant: always on while the card is in a place where it works.
- Triggered: happens automatically when its condition occurs (e.g. 【Deploy】, 【Attack】, 【Destroyed】). Several matching events at once trigger it only once.
- Activated: a player chooses to use it by paying the cost before the colon (【Activate･Main】, 【Activate･Action】).
- Command: the effect of a Command card when played.
- Substitution: "do B instead of A".

## Rules for reading effects
- "You may" = optional. Everything else is done as far as possible (10-1).
- Effects on Units and Bases work only while those cards are in the battle area or shield area, unless the text says otherwise (10-1-2). 【Destroyed】 is the main exception: it works from the trash (13-2-8).
- Targets are chosen when the instruction is reached. If a required target cannot be chosen, that effect does not happen.
- "Can't" beats "can": a prohibition overrides an effect that allows the action.

## Resolution order
- The active player's triggered effects resolve first, then the standby player's.
- If several of your own trigger at once, you choose the order.
- 【Burst】 effects resolve before all other triggered effects (10-1-6-8).
- A new trigger that happens during resolution is resolved first (it jumps the queue).

## Activating an effect (10-3)
Check conditions → declare (reveal the card if it comes from hand) → resolve → handle anything triggered by it.

## Analysis tips
- When judging a card, ask which effect type each part is: constant effects are always "on" value; triggered ones depend on how often the trigger happens; activated ones depend on having the cost available.
- 【Once per Turn】 limits each card's own copy of the effect, so two copies of the same card can each use theirs (13-2-13).
