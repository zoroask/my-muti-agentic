# Your own decklists

Put decklists from your store or your own events here as .txt files (one list per file).
Header lines: `# source:`, `# date: YYYY-MM-DD`, `# event:`, `# kind: tournament`, `# name:`, `# placement:`, `# players:`.
Then `# Main` and one `<count> <card no>` per line. Never include player names.
Collected results from TopDecks HQ and Egman live in ../decklists.jsonl (written by tools/collect_meta.py).
