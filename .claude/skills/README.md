# Skills Library

Reusable prompt skills for this project.

> Note: Claude Code does not auto-load this folder. To make a skill available as a slash command,
> copy or symlink the `.md` file into `.claude/commands/`.

## Available Skills

| File | Purpose |
|---|---|
| `refine-prompt.md` | Improve an agent system prompt with reasoning |
| `debug-agent.md` | Debug why an agent produced bad output |
| `scaffold-agent.md` | Scaffold a new agent definition from scratch |
